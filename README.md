# Express.js To-Do REST API

A simple To-Do REST API built with Node.js and Express.js. It stores to-dos in memory and comes pre-populated with sample data so you can start using it right away.

## Features

- `GET /todos` — returns HTTP 200 and the JSON list of all to-dos.
- In-memory storage with 2 sample to-do items.
- CORS enabled via the `cors` middleware.
