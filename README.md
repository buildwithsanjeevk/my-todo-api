# Express.js To-Do REST API

This is an Express.js To-Do REST API. It provides a simple backend for managing to-do items and currently exposes an endpoint to fetch all to-dos.

## Features

- Node.js and Express.js backend
- CORS enabled
- In-memory sample to-do data
- `GET /todos` endpoint that returns all to-dos as JSON

## Prerequisites

- Node.js installed
- npm installed
